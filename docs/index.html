Why a print edition?

MDN is the JavaScript reference most developers use every day, but it only exists on a screen. Many people learn better from paper: reading on a screen for hours is tiring, hurts some people's eyes, and makes it hard to stay focused.

These books let you study the same material on paper. The wording, code examples and section order are MDN's own, so what you read here is what you will find on the website when you look something up while coding. The collection contains the whole JavaScript section of MDN, not a selection.

What is included

  • The complete JavaScript Guide, including the intermediate and advanced guides.
  • The complete JavaScript Reference: every built-in object with its constructors, methods and properties; statements and declarations; expressions and operators; functions; classes; regular expression syntax; the error reference; lexical grammar, strict mode and iteration protocols.

Not included, because they are separate sections of MDN: the Learn web development beginner tutorials, Web APIs such as the DOM and Fetch, HTML, CSS and the Glossary.

Is it the same as the MDN website?

The content is the same; the layout is redesigned for paper.

  • The article text was checked automatically against MDN for all 1,346 articles.
  • All 6,857 code blocks (49,890 lines) are character-for-character identical to the source, including indentation.
  • Interactive "Try it" examples cannot run on paper; their source code is printed in full.
  • Browser compatibility tables are rebuilt from MDN's browser-compat-data in a compact text form.
  • There is no syntax highlighting; pages are black on white to print cleanly.
  • This is a snapshot. MDN is edited every day, so the website will move ahead of the books.

Full details are in the verification report.

Printing

  • A4 paper, double-sided, flipped on the long edge.
  • Print at "Actual size" or 100 %, not "Fit to page".
  • Margins are mirrored for binding, and every volume has a table of contents, running headers and page numbers.
  • Body text is 11 pt and code is 9.25 pt; a monochrome printer is enough.
